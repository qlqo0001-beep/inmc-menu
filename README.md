# inmc-menu

**Shift+F 플레이어 메뉴.** 한 화면에서 서버 기능(스폰·랜덤 TP·상점·경매장·가방·낚시·콘텐츠·출석 …)으로 가고 개인 설정을 바꾼다.
스폰·랜덤 TP·출석은 이 플러그인이 직접 한다. 다른 inmc 플러그인에는 기대지 않는다 — 버튼은 **명령어로** 그 기능을 열고, 개인 설정은 core
`PlayerSettings` 로만 만난다.

사용법은 `GUIDE.md`, 바꾼 것은 `CHANGELOG.md`. 계획(왜 그렇게 정했나)은 `~/.claude/plans/soft-stargazing-whistle.md`.

## 메뉴

- 메뉴 여러 개(`menus/<id>.yml`, Shift+F 는 `main`). 처음 깔 때만 기본 메뉴 둘(`main` 6줄 · `contents` 4줄)을 만든다 — 폴더에 파일이 하나라도
  있으면 만들지 않는다.
- **버튼 = 직사각형 칸 묶음**(1×1 ~ 9×6). 이름·설명(MiniMessage + PlaceholderAPI, `{플레이어}`·`{플레이타임}`)·대표 아이템(팩 없는 사람용)·그림
  이름·권한(없으면 숨김 또는 잠금)·**동작 목록**(좌·우클릭 따로): 명령어(플레이어로) · 콘솔 · 메뉴 열기 · 내장 화면(설정·출석·랜덤 TP·스폰) ·
  메시지 · 닫기. 특수 버튼 "내 정보"는 그 칸에 진짜 머리를 놓는다.
- 칸 밖·겹친 버튼은 읽을 때 빼서 `rejected` 로 들고 있다가 그대로 다시 쓴다(지우지 않는다) — `/메뉴 검증` 이 알려 준다.

## 리소스팩 GUI (`pack/`)

| 무엇 | 어떻게 |
|---|---|
| 배경 | 창 제목에 **그림 글자 하나**(글꼴 `inmc:menu`). 앞에 공백 −8 로 창 왼쪽 끝, `ascent` 13 으로 창 위끝, 뒤에 −169 로 제목 자리에 돌아와 제목 글씨를 쓴다. 그림 글자는 흰색(제목 색이 곱해지지 않게) |
| 칸 | 아이템은 `(8 + 18·열, 18 + 18·줄)`, 칸 틀은 그 1 바깥. 버튼 판은 칸 틀 묶음을 덮는다 |
| 마우스 | 버튼의 칸마다 **그 자리 그림 조각 아이템**(`inmc:gui/menu/cell/<배경>_<칸>` — 배경과 똑같은 16×16)에 버튼 이름·설명 — 그림 어디에 올려도 같은 이름. 조각이 불투명해 마우스를 올렸을 때 바닐라가 아이템 뒤에 까는 흰 칸(37%)이 가려진다(앞의 12% 덮개는 남는다). 조각 텍스처는 아이템 아틀라스라 `textures/item/` 아래 |
| 높이 | `20 + 18·줄` — 바닐라 가방 부분의 "인벤토리" 글자(`20 + 18·줄`)를 덮지 않는다(어두운 글자가 우리 판 위에서 안 보인다) |

- **그림은 배치에서 그린다**(`ArtRenderer`) — 칸 좌표와 같은 식이라 어긋날 수 없다. `ArtTest` 가 버튼 판 모서리 = 칸 경계를 픽셀로 보고,
  미리보기(`build/art-preview/*-preview.png`, 3배 + 아이템 자리 빨간 선)를 남긴다.
- 글씨는 **갈무리 11 Bold**(BDF, SIL OFL — jar 에 들어 있다)를 직접 그린다(`BdfFont` — java.awt 글꼴 없이). 판에 안 들어가면 간격을 줄이고,
  그래도 넘치면 쓰지 않는다(마우스를 올리면 보인다).
- 기본 아이콘 20종은 코드 도안(`Icons`). `plugins/inmc-menu/art/<그림 이름>.png`(16×16)이 있으면 그것이 이긴다.
- 쓰는 곳: 커스텀아이템 팩 소스 `plugins/inmc-customitems/pack/sources/40-inmc-menu/`(ARCHITECTURE "커스텀아이템 팩 소스 폴더"). 쓴 뒤
  `커스텀아이템 리팩 빌드` 를 부르고, 새 `pack.zip` 에 우리 글꼴이 들어갔는지(그리고 부른 뒤에 만들어졌는지) 2초마다 본다.
- **그림 화면은 확인된 사람에게만**: 팩에 들어갔고(`artReady`) · 그 사람이 팩을 다 받았고(`PlayerResourcePackStatusEvent`) · 그 메뉴를 그린 뒤
  배치·이름·그림을 고치지 않았을 때(`LayoutPrint`). 셋 중 하나라도 아니면 **일반 아이콘 화면**. 새 팩이 나오면 그 전에 받은 사람은 빠진다.
- 배경 글자 번호는 메뉴마다 한 번 정하면 그대로(`drawn.yml`) — 0~5 는 칸 격자(내장 화면 1~6줄), 16~ 는 메뉴.

## 개인 설정

core `PlayerSettings` 에 올라온 것 전부를 올린 플러그인별로(메뉴 → 공용 → 그 밖). 메뉴가 올리는 것: Shift+F 메뉴 · 개인 시간(서버·아침·낮·저녁·밤)
· 개인 날씨(서버·맑음·비) · 다른 플레이어 숨기기(**관리자가 정한 월드에서만**). 다른 플러그인: 희귀 드랍·당첨 공지(core) · 광역 채굴·나무 통째
베기(인첸트) · 배낭 드랍 자동 수납(커스텀아이템). 항목마다 권한(`inmcmenu.setting.<이름>`, 기본 true)을 걸 수 있다.

## 랜덤 TP (`rtp/`)

**누를 때마다 새 무작위 자리. 찾는 일은 3·2·1 카운트다운 뒤에 숨긴다.** 미리 찾아 둔 자리는 쓰지 않는다(사용자 결정 — 이미 밝혀진 곳만 가면 랜덤
TP 가 아니다). 아무도 안 누르면 아무 일도 안 한다.

1. 누르면 화면을 닫고 카운트다운과 **동시에** 찾기 시작.
2. **거르기(워커)** — 고리 안 넓이에 고른 좌표(`Ring`) → 월드 경계 → **실패 구역**(`ChunkMarks` — 가 봤더니 설 곳이 없던 청크, 청크당 1비트,
   `rtp/<월드>.bad`, 월드 씨앗이 바뀌면 버림) → **생물군계를 청크 없이 계산**(`vanillaBiomeProvider` — 바다·강 …). 한 번에 후보 6개.
3. **지역(메인)** — WorldGuard 지역·Lands 땅(청크를 안 읽는 조회).
4. **청크(비동기)** — `getChunkAtAsync(gen, urgent)`.
5. **확인(메인)** — 높이맵으로 지면 y, 발밑·두 칸만(네더는 기둥을 훑음). 청크 안 기둥 4개. 안 되면 그 청크를 실패 구역에 적고 다음 후보.
6. 찾으면 그 청크에 **표를 붙여** 카운트다운 동안 붙잡고, 0 이 되면 그 틱에 `teleportAsync`. 이동한 뒤 표를 뗀다.

부하: 사람마다 찾기 하나(그동안 누르면 "이동 준비 중") · **서버 전체 동시 찾기 수 상한**(기본 2) + 대기열(기본 10, 제목에 "대기 n번째") · 취소한
찾기도 읽던 청크가 올 때까지 자리를 잡는다(움직였다 다시 누르기로 상한을 못 넘게) · 평균 틱이 기준(45ms)을 넘으면 새 찾기를 받지 않는다 ·
찾기마다 청크 8개 상한. 비용은 **이동하는 순간** 받고(못 움직이면 돌려줌) 쿨타임은 이동한 뒤에만. `/야생 상태` 에 월드마다 성공률·걸린 시간·
청크 읽기 수·실패 구역 크기.

## 스폰 (`spawn/`)

- 서버 스폰(`/스폰 설정`) · `/스폰`(대기 — 움직이거나 맞으면 취소, 쿨타임).
- 접속: `AsyncPlayerSpawnLocationEvent` — 들어오기 **전에** 자리를 정한다(처음 접속 · 매 접속).
- 부활: 순서(침대 · 리스폰 앵커 · 서버 스폰 · 월드 스폰)를 관리자가 정하고 끈다. 위에서부터 처음 되는 곳. 침대·앵커는 그 부활이 침대·앵커일 때
  그대로 둔다. 월드 스폰은 죽은 월드(네더·엔드면 기본 월드). 다 안 되면 바닐라. **엔드 귀환은 건드리지 않는다.**

## 출석 (`attend/`)

| 방식 | 칸 | 넘어가면 |
|---|---|---|
| 달력형 | 이번 달 1~31일 + 이달 n일 출석 보너스(기본 7·14·21·28) | 다음 달 새로 |
| 연속형 | 연속 1~N일째 | 하루 빠지면 1일째 · N 다음은 반복/유지 |
| 누적형 | 총 1~N번째 | N 다음은 반복/유지 |

- 판마다 **자동**(접속하면 — 오늘 n분 접속한 뒤, 1분마다 확인해 날이 바뀐 것도 잡는다) / **수동**(오늘 칸을 눌러야 — 들어올 때·날이 바뀔 때 안내).
- 보상 = 아이템(빈 칸에 올려 등록) + 명령어(콘솔, `{player}`) + 돈(기본 화폐). 가방이 차면 **못 받은 보상**에 넣고 출석 화면에서 받는다.
- 하루 경계 = `config.yml` 의 시간대·바뀌는 시각.
- **사용할 달**(`month: 2026-11`): 정하면 그 달에만 화면에 나오고 출석된다 — 달마다 보상이 다른 달력형 판을 미리 만들어 두면 1일에 저절로 바뀐다.
  **복사**는 보상·설정을 그대로(기록은 새로), 달을 정한 판이면 다음 달로 옮기고 id·이름의 달(`2026-10`·`10월`)도 바꿔 둔다(`Board.copyDraft`).
- **초기화**: 판 전체는 회차(`round`)를 올린다 — 기록의 회차가 판과 다르면 없는 기록으로 보므로, 사람마다의 파일을 훑지 않고 접속 안 한 사람에게도 바로
  맞는다. 한 사람은 `/출석 초기화 <플레이어> <판>` — 들어와 있으면 메모리에서, 아니면 워커가 파일에서 그 판만 지운다(못 받은 보상은 그대로).
- **기록을 먼저 쓰고 보상** — 사람마다 파일(`attendance-data/<uuid>.yml`)을 그 자리에서 원자적으로. 보상 뒤에 꺼져 또 받는 것보다, 기록 뒤에 꺼져
  못 받는 쪽을 고른다(업적 `claims/` 와 같은 이유).

## 다른 플러그인과의 경계

- **낚시**: 낚싯대를 든 Shift+F 는 낚시가 LOWEST 에서 가져가 취소한다. 우리는 HIGH `ignoreCancelled`.
- **커스텀아이템**: 팩 소스 폴더에 쓰고 `커스텀아이템 리팩 빌드` 를 부른다. 커스텀아이템이 없으면 그림 화면은 켜지지 않는다(일반 화면).
- **CMI**: CMI 가 `/스폰`·`/출석` 별칭(CustomAlias)이나 스폰·부활 처리를 쥐고 있으면 둘이 겹친다 — 그쪽을 끈다(`GUIDE.md`).
